# ⚡ Dotfiles

A curated collection of configuration files for my personal computing environment. This setup is terminal-centric, Wayland-native, and modularly managed using GNU Stow.

## 🛠️ The Stack

*   **OS:** Arch Linux
*   **WM/Compositor:** Hyprland
*   **Terminal:** Kitty + Zsh
*   **Editor:** Neovim (Kickstart, Oil.nvim, Treesitter) & Visual Studio Code (JetBrains Mono Nerd Font)
*   **Bar & Notifications:** Waybar, SwayNC
*   **Wallpaper & Idle:** Hyprpaper, Hypridle
*   **Utilities:** Ranger, btop

## 📂 Repository Structure

This repository is structured for GNU Stow. Each directory represents a package that can be symlinked directly to the home directory without scattering configuration files manually.
